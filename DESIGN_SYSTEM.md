# Frank's Cancer Journey - Design System

## Overview
A calm, accessible, and cohesive design system focused on healing and hope.

## Color Palette

### Primary Colors (Soft Blue/Green - Calming & Healing)
- **Primary Teal**: `#5FA8A8` - Main brand color
- **Primary Blue**: `#4A90A4` - Secondary brand color
- **Primary Green**: `#6B9080` - Success and growth

### Secondary Colors
- **Sage**: `#A4C3B2` - Soft accent
- **Mint**: `#CCE3DE` - Light backgrounds
- **Sky**: `#B8D4E8` - Info highlights

### Accent Colors
- **Coral**: `#E07A5F` - Warnings and alerts
- **Gold**: `#F2CC8F` - Highlights and warnings
- **Lavender**: `#A8DADC` - Selection and hover states

### Neutral Colors
- **Dark**: `#2D3748` - Primary text (WCAG AAA compliant)
- **Medium**: `#4A5568` - Secondary text
- **Light**: `#718096` - Muted text
- **Lighter**: `#CBD5E0` - Borders
- **Lightest**: `#EDF2F7` - Backgrounds

## Typography

### Font Family
- **Primary**: Inter, -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto
- **Secondary**: Georgia, 'Times New Roman', serif (for quotes)

### Font Sizes (Accessible & Comfortable)
- **XS**: 0.75rem (12px) - Small labels
- **SM**: 0.875rem (14px) - Secondary text
- **Base**: 1rem (16px) - Body text
- **LG**: 1.125rem (18px) - Lead text
- **XL**: 1.25rem (20px) - Subheadings
- **2XL**: 1.5rem (24px) - Section titles
- **3XL**: 1.875rem (30px) - Page subtitles
- **4XL**: 2.25rem (36px) - Page titles

### Line Heights
- Body text: 1.7
- Headings: 1.3

## Spacing System
- **XS**: 0.25rem (4px)
- **SM**: 0.5rem (8px)
- **MD**: 1rem (16px)
- **LG**: 1.5rem (24px)
- **XL**: 2rem (32px)
- **2XL**: 3rem (48px)

## Border Radius
- **SM**: 0.25rem - Small elements
- **MD**: 0.5rem - Buttons, inputs
- **LG**: 0.75rem - Cards
- **XL**: 1rem - Large cards
- **Full**: 9999px - Pills and badges

## Shadows
- **SM**: Subtle elevation
- **MD**: Standard cards
- **LG**: Hover states
- **XL**: Modals and overlays

## Accessibility Features

### Contrast Ratios
- All text meets WCAG AA standards (4.5:1 minimum)
- Large text meets WCAG AAA standards (3:1 minimum)

### Focus Indicators
- 2px teal outline
- 2px offset for clarity
- Visible on all interactive elements

### Mobile Responsiveness
- Navigation collapses at 992px
- Cards stack vertically
- Tables scroll horizontally
- Touch-friendly tap targets (44px minimum)
- Readable font sizes on all devices

### Other Accessibility
- Semantic HTML
- ARIA labels where needed
- Smooth scrolling
- High contrast selection color
- Keyboard navigation support

## Responsive Breakpoints

### Large Desktop (>992px)
- Full multi-column layouts
- Side-by-side cards
- Expanded navigation

### Tablet (768px - 992px)
- Reduced font sizes
- Stacked columns
- Collapsed navigation
- Full-width large buttons

### Mobile (576px - 768px)
- Single column layout
- Compact spacing
- Scrollable tables
- Stacked forms
- Full-width buttons

### Small Mobile (<576px)
- Smallest font sizes
- Maximum touch targets
- Vertical button groups
- Minimal padding

## Animation Guidelines
- Subtle transitions (0.3s)
- Hover lift effects (2px)
- Fade-in for new content
- Slide-in for side panels
- Float animation for icons

## Best Practices
1. Use CSS variables for all colors
2. Maintain consistent spacing
3. Test on mobile devices
4. Ensure keyboard accessibility
5. Provide visual feedback for interactions
6. Keep animations subtle and purposeful
7. Use semantic HTML
8. Optimize for performance
9. Test with screen readers
10. Maintain color contrast ratios

---

**Design Philosophy**: Calm, healing, accessible, and hopeful. Every design decision supports the user's journey toward recovery and wellness.
