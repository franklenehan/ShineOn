Import Data
Important: Importing will merge with existing data. Export a backup first if you want to preserve your current data.
Import from JSON

Restore data from a previously exported JSON backup file.

How to Import
  1. Click "Choose File" to select your backup JSON file
  2. Review the file details shown below
  3. Click "Import JSON Backup" to restore
  4. Wait for confirmation message
  5. Refresh the page to see imported data
